🇫🇷 Français

DetoxScreen t'aide à reprendre le contrôle de ton temps d'écran : blocages par limite d'usage, par plages horaires, par lieu ou permanents, sessions focus, mode strict.

Un problème, une question, une idée ? Écris à support.detoxscreen@gmail.com — réponse rapide garantie. Tu peux aussi nous écrire directement depuis l'app (Réglages → Nous écrire).

Questions fréquentes

  • Le blocage ne se déclenche pas : vérifie que l'autorisation Temps d'écran est accordée (Réglages iOS → Temps d'écran) et que le blocage est activé dans l'app.
  • Un site web n'est pas bloqué : un site n'est bloqué que s'il est sélectionné dans un blocage activé (écran du blocage → section Sites web → la puce du site doit être cochée). Le filtrage couvre Safari.
  • Je ne peux plus modifier mes blocages : le mode strict est probablement actif. Il autorise d'ajouter ou de renforcer, mais empêche d'affaiblir ou de supprimer. Il ne peut être désactivé qu'une fois par semaine.
  • Je ne peux plus supprimer d'apps sur mon iPhone : c'est l'effet du mode strict (limite d'iOS : la protection s'applique à tout le téléphone). Désactive le mode strict dans DetoxScreen → Réglages.
  • Le bouton « Encore 5 min » a disparu : soit le plafond quotidien de sursis est atteint, soit il est réglé sur « Jamais » (Réglages → Sursis), soit le mode strict est actif.

🇬🇧 English

DetoxScreen helps you take back control of your screen time: usage-limit, scheduled, location-based or permanent blocks, focus sessions, strict mode.

Problem, question, idea? Write to support.detoxscreen@gmail.com. You can also reach us from the app (Settings → Contact us).

FAQ

  • Blocking doesn't trigger: check that Screen Time permission is granted (iOS Settings → Screen Time) and that the block is enabled in the app.
  • A website isn't blocked: a site is only blocked when it is selected inside an enabled block (block screen → Websites section → the site's chip must be checked). Filtering covers Safari.
  • I can't edit my blocks anymore: strict mode is probably on. It allows adding or strengthening, but prevents weakening or removing. It can only be turned off once a week.
  • I can't delete apps on my iPhone: that's strict mode (an iOS limitation — the protection applies device-wide). Turn strict mode off in DetoxScreen → Settings.
  • The "5 more min" button is gone: either the daily cap of passes is reached, or it's set to "Never" (Settings → Passes), or strict mode is on.
